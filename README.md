# Job Tracker

A full-stack web application for managing and tracking job applications throughout the job search process.

## 🎯 Project Overview

Job Tracker helps users organize their job applications and keep track of their application status, interviews, notes, and other important details in one place.

## 🚀 Planned Features

* Create and manage job applications
* Track application status
* Search and filter applications
* Pagination
* Dashboard statistics
* Authentication and Authorization
* Interview management
* Responsive Angular UI
